* Overview
Backport the MIPI DSI display pipeline from Linux v6.10 to U-Boot v2026.04 for Allwinner T113-S.

Pipeline: DE2 Mixer → TCON Top → TCON LCD0 → DSI Controller → D-PHY → ILI9881C Panel

* Phase 1: Clock and PHY Foundation [DONE]
- Verified T113-S CCU support for =CLK_BUS_MIPI_DSI= and =CLK_MIPI_DSI=.
- Ported sun6i MIPI D-PHY driver to U-Boot PHY framework.
- Implemented HS/CLK timing calculations and analog power-on sequences for A100/D1 variant.

* Phase 2: Display Pipeline Drivers [DONE]
- Ported sun6i MIPI DSI controller driver as U-Boot DSI host uclass.
- Added DSI TRI-mode support to TCON/LCDC with automatic frame output configuration.
- Extended DE2 driver for DSI output path and NCAT2-specific clock/reset handling.

* Phase 3: Panel and Device Tree [DONE]
- Ported ILI9881C panel driver with =hd50004c30= variant support.
- Integrated full display pipeline (Mixer0 → TCON Top → TCON LCD0 → DSI → Panel) into board DTS.
- Enabled =CONFIG_VIDEO=, =CONFIG_VIDEO_DE2=, and splash screen support in board defconfig.

* Phase 4: Integration and Refinement [IN PROGRESS]
** 4.1 Allwinner U-Boot Comparison & Fidelity Fixes [DONE]
- Performed deep-dive comparison with Allwinner's =u-boot-2018= (brandy-2.0).
- Identified and fixed critical discrepancies:
  - Corrected =CCSC01= (UI channel CSC) offset to =0xFA050= (was incorrectly =0xFA000=).
  - Disabled TCON CCIR CSC by setting bit 19 of =TCON0_HV_IF_REG=.
  - Corrected ILI9881C init command =0xCF= (was =0xBF=) and standardized reset sequence.
- Ensured all Channel 1 VEP unit bases are cleared to prevent stale state.

- Apply =ANA1= bit 5 quirk if =ic_ver > 0= (likely required for T113-S/D1).

* Phase 5: Seamless Kernel Handoff
Minimize display disruption when Linux takes over the display pipeline from U-Boot.

** 5.1 Eliminate Window 1: simplefb framebuffer handoff [DONE]
- U-Boot: Enabled =CONFIG_VIDEO_DT_SIMPLEFB= to patch kernel DTB with live FB info.
- Kernel DTS: Added =framebuffer-lcd0= stub in =chosen= node with required pipeline clocks.

** 5.2 Minimize Window 2: skip panel reset on first boot [IN PROGRESS]
- Add =panel-skip-init= property support to Linux =panel-ilitek-ili9881c.c=.
- Update kernel DTS to include the skip flag for the panel node.

** 5.3 Keep display active during application startup: framebuffer console [IN PROGRESS]
- Enable =CONFIG_FRAMEBUFFER_CONSOLE= and DRM fbdev emulation in kernel.
- Verify boot messages transition smoothly from splash to console.

** 5.4 Eliminate pre-systemd blank: initramfs one-shot splash [PAUSED]
- Implement statically linked =drm-set-splash= for initramfs execution.
- Add initramfs hooks to display image before the rootfs is mounted.

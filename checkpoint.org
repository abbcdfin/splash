* Technical Background

** Clock Tree (Verified Working)
- PLL_VIDEO0_4X (CCU 0x040): 1596 MHz
  - Formula: 24 MHz * N / M
  - N=133, M=2 (register stores N-1 and M-1)
  - Register: bits 15:8 = N-1 = 132, bit 1 = M-1 = 1
  - Derivatives: PLL_VIDEO0_2X (798 MHz), PLL_VIDEO0_1X (399 MHz)

- Display Engine: 399 MHz (PLL_VIDEO0_4X / 4)
- TCON_LCD0: 399 MHz from PLL_VIDEO0_1X
- TCON internal dclk: 99.75 MHz (399 / 4 for DSI timing reference)
- DSI HS bit clock: 399.168 Mbps/lane
- Pixel clock: 66.528 MHz

** DSI Command Transmission (Verified Working)
- Commands sent in LP mode using DSI_INST_ID_LPDT
- Packet format verified against Linux kernel
- Example matching packet:
  - U-Boot: DSI_LP: SHORT type=0x15 len=2 pkt=0x03000115 data=01 00
  - Linux:  DSI_LP: SHORT type=0x15 len=2 pkt=0x03000115 data=

** Critical Registers from Linux (Working System)

*** DSI Controller (Base: 0x05450000)
- SUN6I_DSI_CTL_REG (0x000): 0x01010001
- SUN6I_DSI_BASIC_CTL_REG (0x00c): 0x00000000
  - Correct for sync pulse mode (no burst mode bits)
- SUN6I_DSI_BASIC_CTL0_REG (0x010): 0x00030001
  - Bit 16: ECC_EN enabled
  - Bit 17: CRC_EN enabled
  - Bit 0: INST_ST (instruction start)
- **SUN6I_DSI_BASIC_CTL1_REG (0x014): 0x000051f7** ⚠️ CRITICAL
  - Bit 0: VIDEO_MODE - MUST be set for video output
  - Bit 1: VIDEO_PRECISION
  - Bit 2: VIDEO_FILL
  - Bits 15:4: VIDEO_ST_DELAY(1311) - delay between TCON and DSI video

*** DE2 Blender (Base: MUX0 + 0x1000)
- PIPE_CTL (0x00): 0x00000100
  - Bit 8: Enable pipe 0 (REQUIRED for output)
- ROUTE (0x80): 0x00000001
  - Pipe 0 source = channel 1
- ATTR[0].INSIZE (0x08): 0x04ff02cf
  - (1279 << 16) | 719 for 720x1280
- OUTSIZE (0x8c): 0x04ff02cf
- BLD_MODE[0] (0x90): 0x03010301
- OUTCTL (0xfc): 0x00000000 (progressive)

*** clock_set_pll3() - Fixed PLL_VIDEO0 calculation
#+begin_src c
static inline void clock_set_pll3(unsigned int hz)
{
    /* PLL_VIDEO0 formula: 24 MHz * N / M */
    /* Register: bits 15:8 = N-1, bit 1 = M-1 */
    u32 m, n;

    /* Special case for 1596 MHz: use N=133, M=2 */
    if (hz >= 1590000000 && hz <= 1600000000) {
        n = 133;
        m = 2;
    } else {
        /* General case: M=1 (no divider) */
        n = hz / 24000000;
        m = 1;
    }

    if (n < 8) n = 8;
    if (n > 255) n = 255;

    u32 reg = readl((u8 *)SUNXI_CCM_BASE + 0x40);
    reg &= ~((0xff << 8) | (1 << 1)); /* Clear N (15:8) and M (bit 1) */
    reg |= ((n - 1) << 8) | ((m - 1) << 1);
    /* Set EN(27), LOCK_EN(29), LDO_EN(25:24), and OUT_EN(31), plus BIT(30) per Linux probe */
    reg |= BIT(31) | BIT(30) | BIT(29) | BIT(27) | (3 << 24);

    printf("CCU: PLL_VIDEO0 setup: %u Hz (n=%u, m=%u, reg=0x%08x), base=0x%x\n", hz, n, m, reg, SUNXI_CCM_BASE);
    writel(reg, (u8 *)SUNXI_CCM_BASE + 0x40);
    mdelay(5);

    int timeout = 2000;
    while (!(readl((u8 *)SUNXI_CCM_BASE + 0x40) & BIT(28)) && timeout--)
        udelay(10);

    u32 final = readl((u8 *)SUNXI_CCM_BASE + 0x40);
    if (timeout <= 0)
        printf("CCU: PLL_VIDEO0 lock timeout! (reg=0x%08x)\n", final);
    else
        printf("CCU: PLL_VIDEO0 locked.\n");
}
#+end_src

*** clock_get_pll3() - Fixed readback calculation
#+begin_src c
static inline unsigned int clock_get_pll3(void)
{
    u32 reg = readl((u8 *)SUNXI_CCM_BASE + 0x40);
    u32 n = ((reg >> 8) & 0xff) + 1;
    u32 m = ((reg >> 1) & 0x1) + 1;
    printf("CCU: PLL_VIDEO0 get: (n=%u, m=%u, reg=0x%08x)\n", n, m, reg);
    return (n * 24000000) / m;
}
#+end_src

* Key Discoveries

** 1. PLL Clock Calculation Bug
- Issue: M field is only bit 1, not bits 1:0
- For 1596 MHz: Must use N=133, M=2 (not N=66, M=1)
- Register stores (N-1) and (M-1), so bit 1 = 1 means M=2

** 2. DE2 Blender PIPE_CTL Mislabeling
- U-Boot structure labels register 0x00 as "fcolor_ctl"
- Actually the PIPE_CTL register
- Bit 8 must be set to enable pipe 0
- Bits 3:0 control fill color enable (should be 0 to use channel data)

** 3. DSI Command Transmission Verified
- All commands sent correctly in LP mode
- Packet headers match Linux kernel exactly
- 190 init commands + exit_sleep_mode + set_display_on all correct
- Command transmission is NOT the issue

** 4. Critical DSI Register: BASIC_CTL1
- Must have bit 0 (VIDEO_MODE) set for video output
- Linux sets this in sun6i_dsi_encoder_enable()
- Value should be 0x000051f7 with VIDEO_ST_DELAY(1311)
- Without VIDEO_MODE bit, DSI stays in command mode only

* Critical Hardware Knowledge

** PLL_VIDEO0 Clock (CCU 0x040)
- Formula: 24 MHz * N / M
- M field is BIT 1 ONLY (not bits 1:0)
- For 1596 MHz: N=133, M=2 (register stores N-1 and M-1)

** DE2 Blender
- Register at offset 0x00 is PIPE_CTL (mislabeled "fcolor_ctl" in U-Boot struct)
- Must set bit 8 to enable pipe 0, otherwise no output

** DSI Controller
- BASIC_CTL1 (0x014) bit 0 = VIDEO_MODE must be set for video output
- Linux working value: 0x000051f7 (VIDEO_ST_DELAY=1311)
- LP mode for DCS commands, HS mode for video stream

** panel-skip-init Pattern
- Use =of_property_read_bool(ctx->dsi->dev.of_node, "panel-skip-init")=
- NOT =device_property_read_bool= (fwnode may not be set up, debug log never appeared)
- Static first-boot flag ensures skip only applies once (suspend/resume still reinits)

#+TITLE: U-Boot T113-S MIPI DSI Display Clock Implementation

* CCU Root PLL Initialization

** PLL_PERIPH0 (PLL6) - 594 MHz
   - **Register:** CCU 0x020
   - **When:** Early boot in clock_init_safe() (arch/arm/mach-sunxi/clock_sun50i_h6.c:47)
   - **Value:** CCM_PLL6_DEFAULT = 0xe8216300 (R528/T113-S)
   - **Calculation:**
     - N=99 (bits 15:8), M=1 (bit 1=0), post-div=2 (bits 18:16)
     - PLL_PERIPH0_4X = 24 MHz × 99 = 2376 MHz
     - PLL_PERIPH0_2X = 2376 / 2 = 1188 MHz
     - PLL_PERIPH0_1X = 1188 / 2 = **594 MHz**
   - **Status:** ✅ Correctly initialized before display framework

** PLL_VIDEO0 (PLL3) - ~1596 MHz Target
   - **Register:** CCU 0x040
   - **When:** Display init in clock_set_pll3() (arch/arm/include/asm/arch-sunxi/clock_sun50i_h6.h:23)
   - **Called from:** drivers/video/sunxi/sunxi_lcd.c:109
   - **U-Boot Current:**
     - N = 1596/24 = 66, M = 1 (cleared by code)
     - Result: 24 MHz × 66 / 1 = **1584 MHz** (~12 MHz low)
   - **Linux Reference:** 0xf9008402
     - N = 133, M = 2
     - Result: 24 MHz × 133 / 2 = **1596 MHz** (exact)
   - **Status:** ⚠️ Correct timing (subsystem init), but should use M=2 for accuracy

** Recommended Fix for PLL_VIDEO0
   #+begin_src c
   // In clock_set_pll3():
   u32 n = (hz * 2) / 24000000;      // Adjust for M=2
   reg |= ((n - 1) << 8) | BIT(1);   // Set N and M=1 (divisor=2)
   #+end_src

* Module Clocks

** CLK_MIPI_DSI (CCU 0xb24)
   - **Parent:** PLL_PERIPH0_1X (594 MHz)
   - **Config:** Mux=1, M=3 (div by 4), Gate=1
   - **Result:** 594 / 4 = **148.5 MHz** (target 150 MHz)
   - **Init:** D-PHY driver (phy-sun6i-mipi-dphy.c:sun6i_dphy_init)

** CLK_TCON_LCD0 (CCU 0xb60)
   - **Parent:** PLL_VIDEO0_1X (1596 / 4 = 399 MHz)
   - **Config:** Mux=0, M=0, P=0 (div by 1), Gate=1
   - **Result:** **399 MHz** (DSI bit clock per lane)
   - **Init:** Display driver (sunxi_lcd.c:112)

** TCON0_DCLK (TCON 0x44)
   - **Parent:** CLK_TCON_LCD0 (399 MHz)
   - **Divider:** 4 (SUN6I_DSI_TCON_DIV)
   - **Result:** 399 / 4 = **99.75 MHz**
   - **Purpose:** DSI interface timing reference (NOT pixel clock)
   - **Note:** TCON-internal register, isolated from CCU

* Initialization Architecture

** Timing
   1. **Early Boot:** PLL_PERIPH0 → 594 MHz (system-wide)
   2. **Display Init:** PLL_VIDEO0 → ~1596 MHz (subsystem-specific)

** Rationale
   - System PLLs: Initialized early, always needed
   - Subsystem PLLs: On-demand when subsystem enables
   - Matches Linux kernel pattern
